# سجل الشرائح (تطبيق أندرويد)

يعمل بدون إنترنت. البيانات تُحفظ على الهاتف، والإشعارات (قبل الفصل بيوم ويوم الفصل والمنبهات) يطلقها الهاتف نفسه.

## بناء ملف APK
1. أنشئ مستودعًا جديدًا خاصًا على GitHub.
2. ارفع كل محتويات هذا المجلد إلى المستودع (بما فيها المجلد المخفي `.github`).
3. افتح تبويب Actions، وسيبدأ البناء تلقائيًا (أو اضغط Run workflow). يستغرق نحو 5 دقائق.
4. بعد النجاح افتح Releases في المستودع وحمّل `app-debug.apk` على هاتفك وثبّته.
   (يطلب أندرويد السماح بالتثبيت من مصدر غير معروف.)
5. عند أول فتح اسمح بالإشعارات.

## مشاركة البيانات بين الأجهزة
الإعدادات ← تصدير نسخة ← أرسل الملف للجهاز الآخر ← الإعدادات ← استيراد ودمج.
يؤخذ الأحدث تعديلًا لكل سجل.
